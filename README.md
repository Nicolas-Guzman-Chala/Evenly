**Plataforma de Gestión de Eventos y Venta de Entradas**


**Descripción del proyecto**

Este proyecto consiste en el desarrollo de una plataforma de gestión de eventos y venta de entradas, donde los usuarios pueden explorar eventos, seleccionar asientos, realizar compras y recibir notificaciones sobre el estado de sus transacciones.

El sistema también permite la administración completa de eventos, recintos, zonas, asientos y compras, además de la generación de reportes y el manejo de incidencias operativas.

**Pensamiento computacional**
La carpeta DOCUMENTACION DEL PROYECTO  contiene el archivo del pensamiento computacional junto con el link al diagrama de clases, y un archivo adicional acerca de la justificacion del uso de los patrones de diseño.

Este documento corresponde a la primera fase del proyecto y sirve como base para el diseño del sistema.

**Diseño del sistema**

El sistema fue diseñado aplicando principios de programación orientada a objetos y patrones de diseño, con el objetivo de mejorar la modularidad, escalabilidad y mantenibilidad.

Se implementaron los siguientes patrones:

Singleton
Abstract Factory
Builder
Composite
Decorator
Adapter
Strategy
Observer
State

Cada patrón fue seleccionado según una necesidad específica dentro del sistema, permitiendo resolver problemas de diseño de manera estructurada.

**Interfaz gráfica**

Los archivos relacionados con la interfaz gráfica corresponden a avances del desarrollo en JavaFX.

Estos se encuentran en proceso de integración con la lógica del sistema y sirven como base para la experiencia del usuario final.

**Estado del proyecto**

El proyecto se encuentra en fase de desarrollo, con el diseño arquitectónico definido y los módulos principales en implementación.

Actualmente se trabaja en la integración de la lógica del sistema con la interfaz gráfica y la consolidación de los patrones de diseño.
